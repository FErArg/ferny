# ferny-xmlsnippets

Plugin para Ferny basado en el plugin **xmlsnippets** de [Geany-Plugins](https://plugins.geany.org/).

## Origen

- **Plugin original**: xmlsnippets
- **Autor original**: Desconocido
- **Versión Geany**: 0.x
- **Licencia**: GPL-2.0-or-later

## Adaptación para Ferny

Este plugin ha sido **adaptado desde el código C original de Geany** para funcionar en Ferny usando la API de plugins Lua (API 0). Las principales diferencias:

- **Lenguaje**: Reescrito en Lua 5.4 en lugar de C/GTK
- **API**: Usa la API de plugins de Ferny (, , etc.)
- **Sandbox**: Ejecuta en el sandbox de Ferny (sin , , , , , )
